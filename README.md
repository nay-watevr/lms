# Ruang Belajar — LMS PTIK B

Platform pembelajaran daring berbasis web untuk kelas PTIK B. Aplikasi ini dikembangkan sebagai proyek mata kuliah **Manajemen Proyek Teknologi Informasi (MPTI)** di Universitas Negeri Medan.

## 🌐 Akses Website

**Website:** https://ruang-belajar-ptik-b.infinityfreeapp.com

> Jika website tidak dapat diakses, periksa kembali status hosting atau hubungi anggota tim pengembang.

## ✨ Fitur Utama

- Autentikasi pengguna dengan peran pengajar dan mahasiswa.
- Dashboard berdasarkan peran pengguna.
- Pengelolaan dan akses materi pembelajaran.
- Kuis pilihan ganda dengan batas waktu dan penilaian otomatis.
- Forum diskusi dan balasan.
- Tampilan responsif untuk desktop dan perangkat seluler.

## 🚀 Menjalankan Secara Lokal

1. Pasang dan jalankan Apache serta MySQL menggunakan XAMPP atau lingkungan PHP/MySQL yang setara.
2. Salin source code ke direktori web server lokal, misalnya `htdocs/ruang-belajar-lms-ptik-b/`.
3. Buat database sesuai konfigurasi aplikasi, lalu impor file SQL database jika tersedia di repository.
4. Sesuaikan pengaturan koneksi database pada file konfigurasi. Jangan mengunggah kredensial database asli ke repository publik.
5. Buka `http://localhost/ruang-belajar-lms-ptik-b/` melalui browser.

Nama folder, file SQL, dan konfigurasi dapat berbeda sesuai struktur source code pada repository.
